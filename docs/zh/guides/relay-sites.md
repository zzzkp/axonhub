# 中转站指南

本指南介绍如何在 AxonHub 中管理外部中转站资源。当前中转站功能首期支持 `new-api` 类型站点，用于集中维护站点配置、同步远端资源、执行签到，并在需要时显式导入远端 API Key 为 AxonHub 渠道。

## 什么是中转站？

**中转站**是 AxonHub 管理外部 new-api 站点的独立功能模块。它负责保存站点信息和访问凭据，并调用远端 new-api 管理接口同步资源快照。

中转站可以帮助你：

- 添加和维护 new-api 站点配置。
- 使用访问令牌或账号密码连接远端站点。
- 同步远端 API Key、分组、余额和模型价格。
- 手动执行签到，或为站点开启自动签到。
- 将选定的远端 API Key 显式导入为 AxonHub 渠道。

## 与渠道的关系

中转站和渠道是两个独立概念。

| 功能 | 作用 |
|------|------|
| 中转站 | 管理外部 new-api 后台资源，保存远端资源快照 |
| 渠道 | 参与 AxonHub 请求转发链路，向上游模型服务发送请求 |

中转站不会自动参与请求转发，也不会自动替代现有渠道。只有当你在中转站页面中执行“导入为 Channel”操作后，AxonHub 才会使用选定的远端 API Key 创建一个普通渠道。导入后，渠道仍按 [渠道管理](channel-management.md) 中的规则独立配置和使用。

## 创建 new-api 站点

1. 进入 AxonHub 管理界面 -> **中转站**。
2. 点击 **新建站点**。
3. 填写站点基础信息：
   - **名称**：站点显示名称。
   - **类型**：当前选择 `new-api`。
   - **Base URL**：new-api 站点地址。
   - **状态**：启用或禁用。
   - **备注**：可选说明。
4. 选择认证方式并填写凭据。
5. 保存站点配置。

编辑站点时，如果凭据字段留空，系统会保留原有凭据。

## 认证方式

### 访问令牌

访问令牌方式会向远端请求携带 `Authorization` 和 `New-Api-User` 信息。使用这种方式时，需要提供：

- 访问令牌。
- new-api 用户 ID。

### 账号密码

账号密码方式会先调用远端登录接口获取 session cookie，再用该 session 访问管理接口。

如果远端站点启用了 Turnstile 或其他登录风控策略，账号密码登录可能会被远端策略拦截。这种情况下应优先使用访问令牌方式。

## 同步远端资源

在站点列表中点击 **同步** 后，AxonHub 会调用远端 new-api 接口并更新本地快照。当前同步内容包括：

- 远端 API Key。
- 用户可用分组。
- 用户余额。
- 模型价格。

同步成功后，站点列表展开区会展示余额、分组和模型摘要。远端 API Key 可以通过操作列中的 API Key 管理弹窗查看和维护。

同步失败时，站点会记录错误信息。常见原因包括 Base URL 不可访问、凭据失效、用户 ID 不匹配、远端接口权限不足或远端登录策略拦截。

## API Key 管理

中转站页面提供远端 API Key 管理入口。当前支持：

- 查看已同步的远端 API Key 快照。
- 创建、编辑和删除远端 API Key。
- 为所有分组创建 API Key。
- 将选定 API Key 导入为 AxonHub Channel。

导入为 Channel 时，需要用户明确填写渠道类型、Base URL、支持模型和默认测试模型等渠道字段。该操作不会自动同步后续变更，也不会改变请求转发链路。

## 签到

中转站支持两种签到方式：

- **手动签到**：在站点操作中点击签到，立即调用远端 new-api 签到接口。
- **自动签到**：在站点配置中开启自动签到后，后台任务会每天执行一次签到。

签到结果会记录到签到日志中，可在站点操作列的签到记录弹窗中查看成功或失败信息。

new-api 返回的内部 quota 会按 `500000 quota = 1 USD` 换算为 USD 展示，同时保留原始 quota 值便于核对。

## 使用建议

- 先创建站点并执行同步，确认余额、分组和模型价格能正常拉取。
- 需要进入请求转发链路时，再选择具体 API Key 导入为 Channel。
- 导入后在渠道管理中补齐模型映射、负载均衡和测试配置。
- 如果远端站点有登录风控，优先使用访问令牌认证。
